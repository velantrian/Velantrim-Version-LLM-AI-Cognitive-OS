# Cognitive AI Research Mapping

**Date:** 2026-08-22  
**Status:** RESEARCH ORIENTATION · DOCS ONLY · NOT RUNTIME AUTHORITY

## Purpose

This note maps external cognitive-AI mechanisms to the current Velantrim architecture without turning technology names into architecture commitments.

Core rule:

```text
human capability
→ owning semantic domain
→ bounded mechanism
→ benchmark / evidence
→ explicit owning-project decision
```

Not:

```text
interesting technology
→ mandatory architecture
```

## Candidate map

### ACT-R
Research analogue for activation, recency, frequency and retrieval priority. Existing Velantrim overlap includes EITI DAAD/ranking/decay. Any generalized salience contract should be benchmarked before promotion.

### LIDA / Global Workspace Theory
Research analogue for limited attention, situation modeling, competition and broadcast-like access. Suitable only as bounded attention research; no consciousness claim follows from implementing such a mechanism.

### SOAR
Research analogue for goal/operator cycles, working state and controlled next actions. Relevant to orchestration and task-position continuity, but not a replacement architecture.

### GraphRAG / Graphiti / temporal graph retrieval
Useful for structural, temporal and community-aware retrieval. Natural research host: Titan. Crystal may define compatibility/evidence boundaries, but graph relation or retrieval path never becomes truth or corroboration by itself.

### MemGPT / Letta
Useful comparative baseline for tiered memory and persistent agent state. Velantrim intentionally decomposes this problem across EITI, Crystal, Soul and Continuum. Persistent context management is not equivalent to truth or identity continuity.

### REFRAG / retrieval-context compression
Research candidate for reducing retrieval-context cost and latency while preserving task quality. Evaluate only after stable baselines exist.

### AGRAG / advanced graph retrieval
Research candidate for structured graph retrieval/reasoning paths. Compare against simpler lexical, dense, hybrid and GraphRAG baselines before adoption.

### PAD / affect state
Real research gap: current architecture supports emotional calibration and character/presence semantics, but a formal bounded affect-state contract is not yet a current runtime primitive. Best semantic owner: Soul.

### Emotional RAG
Research candidate for soft affect-aware retrieval/ranking. Inferred emotion must remain attributed, uncertain and provenance-aware; it cannot grant truth, identity or action authority.

### Piaget-style developmental cognition
Research candidate for staged adaptation and schema revision. Best route: Soul development research with Continuum lineage/continuity constraints.

### HTM / Numenta, Hyperon / MeTTa, sparse biologically inspired models, neuromorphic substrates
Future research candidates only. They should enter Velantrim only when a measured problem and cheaper baseline justify an experiment. Native Kernel may test substrate independence, but does not mandate these technologies.

## High-value research gaps

1. **Formal affect-state contract** — time-bound, attributed, uncertain affect that may influence interaction/attention without truth or identity escalation.
2. **Unified salience / activation contract** — importance + recency + frequency + novelty + goal relevance + affect relevance + uncertainty, while keeping salience separate from epistemic confidence.
3. **Bounded attention / workspace experiment** — candidate competition, limited workspace and broadcast-like access, with behavioral metrics and no consciousness claims.
4. **Unified retrieval benchmark** — lexical/BM25, dense, hybrid, GraphRAG/community-aware, temporal graph, and later compression approaches on one controlled evaluation surface.
5. **Role-based model regression / admission** — reasoner, coder, researcher, interaction, creativity, latency, cost and reliability evaluated separately.
6. **Developmental cognition with lineage** — controlled change to beliefs/strategies/self-model while preserving provenance, reversible history and authority boundaries.

## Research intake contract

Every mechanism should record:

- source / paper / implementation reference;
- human capability to improve;
- owning project;
- current Velantrim baseline;
- measurable hypothesis;
- benchmark and negative tests;
- authority impact;
- provenance and maturity;
- rollback/rejection condition;
- status from research intake through explicit owning-project decision.
